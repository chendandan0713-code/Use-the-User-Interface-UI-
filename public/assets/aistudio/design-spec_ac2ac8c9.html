UI DESIGN SPECIFICATION · V1.0

数据大屏界面设计方案
——以「科技质感外边框」为核心

基于参考截图还原并重构大屏外边框语言：深海军蓝底色、双层细描线、22px 切角、L 形角标、六角名匾与刻度侧翼。 在此基础上补齐栅格、色彩、字体与组件规范，使边框可复用到任意业务大屏，同时保证远距离可读与操作习惯的连贯。

画布 1920 × 1080 随分辨率等比缩放 主色 #3FD0FF 底色 #02070E → #08233C 适配 3m 外可读 含 悬浮弹窗 规范
01

设计原则

大屏不是放大的网页。它有三个硬约束：观看距离远、没有鼠标、信息只在固定位置刷新。方案围绕这三点收敛装饰与信息层级。

P-01

一屏一焦点

中央地图区占约 44% 视觉权重，左右两栏为支撑信息。装饰线条透明度一律 ≤ .46，不参与信息竞争。

P-02

边框让位于内容

所有框线与角标收在距边缘 18px 内，内容安全区保留 48px；标题牌与侧翼只占顶部 68px 高。

P-03

三级明度对比

主文字 #DCF2FF、次文字 #8FB6D4、辅助 #5D8AAA，与底色的对比度分别为 13:1 / 6.4:1 / 3.4:1，保证 3m 外层级可辨。

P-04

色彩不是唯一编码

状态区分同时用「颜色 + 文字 + 形状」三重编码，异常状态必须以文案标注「故障／告警」，不做纯色点表达。

02

外边框结构解剖

边框由 6 个图层叠加而成，从内到外依次为：外发光 → 主框线 → 内框线 → 角部构件 → 顶部名匾与侧翼 → 侧边／底部收口。下面按层标注位置与参数。

1
六角名匾（Title Plate） 580×60，左右斜边水平投影 30px；主描边 1.4px #54DAFF、内描边 0.35、底部亮线 264×1.6 带模糊。名匾中心对齐画布中线。
2
双侧翼（Wings） 主线 1.4px 渐变（透明度 0 → .95），副线 1px／45%；梳齿 300×9、节距 16px；端头菱形 4px 作视觉收尾。
3
外框线 / 内框线 外框 1.2px rgba(96,214,255,.46)，内框 1px rgba(96,214,255,.15)，二者间距 9px。双线是"科技感"的关键，也是强弱层次所在。
4
切角与角标 切角 22px（斜边高亮 3px 圆头 + 模糊 2.5）；L 形角标 2px／长 78，内侧再落一层 1px／长 118／透明度 .30，形成三线夹角层次。
5
侧边梳齿 10×176 竖向刻度（节距 16px）+ 三条短枝刻度，对称分布于左右两侧中段，用来平衡顶部侧翼的重量。
6
外发光层 同一条路径描 12px、不透明度 .10、高斯模糊 6，让深色屏体从背景中"浮起"，替代大面积光晕。
为什么要双层线：单线在 2K/4K 拼接屏上会被像素放大成"锯齿硬边"，双线（1.2px + 1px、间距 9px）在两个分辨率下都保持"细而不抖"，且渐变叠色后不会发白。

06

组件规范

所有模块复用同一套组件，保证"每一块看起来是同一台机器产的"。

面板容器

1px 描边 rgba(70,180,235,.18) + 内阴影 34px；左上／右下各一段 12px 角线（1.5px，#5ADCFF 50%）。
标题行底部 1px 渐变线（左亮右隐）+ 64px 高亮段带 10px 外发光；徽标为双层六角形。

溢出处理

列表超出时不做滚动条，改为底部 14% 渐隐遮罩（mask-image），并配「查看全部 ›」入口。
大屏无鼠标，滚动条既无效又破坏版式完整性。

规范要点

  • 状态 = 色点 + 文案，缺一不可（色弱用户 + 远距离都能识别）
  • 数值右对齐、等宽；单位降一级字号并置灰
  • 同屏语义色不超过 3 种，第四种起改用中性色分类
  • 标签用 设备状态 这类描边小标签，不用实心块
  • 金额统一两位小数 + 千分位；单位「万元」在轴标题声明
  • 空数据展示「暂无数据」，不留空白网格
07

统计图悬浮弹窗（Tooltip）

悬浮弹窗是图表的「数据补读层」：图表只负责趋势，精确数值交给弹窗。它必须压得住底层图形，又不能挡住正在看的那个点—— 所以统一采用深色实底 + 细描边 + 与面板同款角线的语言，视觉上像"从面板里长出来的一块"。

定位与避让

  • 轴向吸附：柱状图吸附到柱中心、折线图吸附到最近数据点，不随光标逐像素移动（否则整块会抖）
  • 四向翻转：默认右上；距视口边缘 < 24px 时依次尝试 左上 → 右下 → 左下
  • 永不遮挡：弹窗边界与被指向图元保持 ≥ 12px 间距
  • 大屏适配：无鼠标场景改为点击锁定（再次点击或点空白关闭），弹窗固定在触发点右侧，不做跟随动画

类型与交互时序

  • 单值型：标题 + 一条数值 + 一行补充（峰值时段／占比），宽度取最小 180
  • 多序列型：每个序列一行，色点 + 名称左对齐、数值右对齐等宽，底部固定一行「环比」
  • 告警标注型：描边与色条转红，标题后加「告警」小标签，必须写明触发原因（低于阈值 X）

时序参数

  • 移入延迟 80ms 出现（防抖，避免扫过时满屏乱闪）
  • 淡入 120ms + 上移 4px；移出 100ms 淡出
  • 数据变化时只更新数值，不重播入场动画

禁忌

  • 不用白底／浅底——破坏深色一致性，值班环境刺眼
  • 不放操作按钮、链接、滚动条——大屏点不到，鼠标场景也只是补读
  • 不同时弹出多个（同图保持单例）
  • 涨跌不靠颜色单独编码，必须带 + / − 符号；正向 #3DDC97、负向 #FF6B7A

实现要点

/* 1. 容器：绝对定位 + 轴向吸附，不用 left/top 跟随光标 */
.tip {
  position: absolute;
  background: rgba(6,26,46,.96);
  border: 1px solid rgba(63,208,255,.45);
  box-shadow: 0 12px 30px rgba(0,10,20,.70);
  opacity: 0;
  transition: opacity .12s ease, transform .12s ease;  /* 120ms 淡入 */
}
.hit:hover .tip { opacity: 1; transform: translate(-50%,0); }

/* 2. 角线：与面板同款，左上 + 右下 —— 保证"同一台机器产的" */
.tip::before, .tip::after {
  content: ""; position: absolute; width: 11px; height: 11px;
  border: 1.5px solid rgba(90,220,255,.65);
}

/* 3. 边缘避让：距视口边缘 < 24px 翻到对侧 */
function place(tip, x, y) {
  var r = tip.getBoundingClientRect();
  var flipX = (x + 12 + r.width)  > innerWidth  - 24;
  var flipY = (y - 12 - r.height) < 24;
  tip.style.left = (flipX ? x - 12 - r.width : x + 12) + 'px';
  tip.style.top  = (flipY ? y + 12 : y - 12 - r.height) + 'px';
}
08

动效与可用性

动效参数

中心环呼吸 3.6s ease-in-out；雷达扫描 9s linear；面板数据刷新 200ms 淡入 + 上移 4px；
刷新频率 ≥ 5s 的模块才允许入场动效，避免持续抢注意力。

安全边界

禁止大面积闪烁、频率 > 3Hz 的闪动（光敏性癫痫风险）、
大面积高饱和红／绿填充（值班室长时间注视易疲劳）。

大屏可用性自查

检查项标准说明
首屏模块数≤ 7 个超过 7 个需要分屏或轮播，人眼一次只能抓 5±2 个信息块
单模块指标数≤ 5 个主指标 1 个 + 辅助 4 个，其余进详情页
最小字号10.5px3m 观看距离下的下限，图例也在内
对比度主文字 ≥ 7:1次文字 ≥ 4.5:1；禁止 #5D8AAA 以下灰蓝承载正文
色彩独立性三重编码颜色 + 文字 + 图标／形状，任一维度单独可辨
鼠标依赖零悬停所有关键信息直接可见，hover 只做补充，不做必要信息载体
刷新一致性布局零抖动数字位宽固定，避免 9→10 位时整行位移
09

复用到其他大屏

边框是独立图层，与内容解耦。改造只涉及四个位置，无需动内容结构。

// 1. 换平台名称（≤14 字，字号 26–28）
<h1>西宁市取用水平台 </h1>

// 2. 换主色：只需改 4 处 —— 主框线、名匾描边、侧翼渐变、图表渐变
--cyan: #3FD0FF;              /* 主强调 */
stroke="rgba(96,214,255,.46)"  /* 主框线 */
#lgPlate 渐变：#0E3A62 → #06182C

// 3. 等比缩放（避免非 16:9 屏体变形）
function fit() {
  var s = Math.min(innerWidth / 1920, innerHeight / 1080);
  stage.style.setProperty('--s', s);
}

// 4. 超宽拼接屏（3840×1080）：三栏改四栏，中栏地图保持 1fr
grid-template-columns: 470px 1fr 470px;  /* → 470px 1fr 470px 470px */
